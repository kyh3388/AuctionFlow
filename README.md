# AuctionFlow
온라인 경매 사이트(2026.06 ~ 2026.08)

.java .jsp .css 및 쿼리 파일만 커밋했습니다.


##개발환경
- Java 21
- Eclipse IDE 2025-06
- CoreFrame 6
- MySQL 8.0.
- Apache Tomcat 11
- JSP, JS

##기능
[회원]
- 회원가입
- 로그인 / 로그아웃
- 아이디 중복 확인
- 비밀번호 단방향 해시 저장
- 회원 정보 수정
- 아이디/비밀번호 찾기

[회원 권한]
- 미로그인 사용자의 입찰, 경매 등록 차단
- 본인 상품 입찰 차단

[경매 상품]
- 상품 등록 즉시 경매 시작
- 카테고리 선택
- 대표 이미지, 추가 이미지 업로드
- 상품 설명
- 종료 기간 설정
- 시작가 설정
- 목록 / 상세 조회
- 검색(작품 제목) 
- 최신순, 과거순, 시작가 높은순, 시작가 낮은순 정렬

[입찰]
- 입찰 팝업 및 입찰 처리
- 입찰 금액이 (현재가+호가 단위) 이상인지 검증
- 종료 시각 이후 입찰 차단
- 입찰 이력 저장
- 최고 입찰가, 최고 입찰자 갱신
- 최근 입찰 이력 표시
- 동시 입찰 트랜잭션 처리
- 입찰 성공, 실패 처리

[경매 종료]
- 상태 관리: ONGOING / SOLD / UNSOLD / CANCELED
- 종료 시각 도달 시 낙찰 또는 유찰 처리
- 종료 후 입찰 차단
- 판매자, 낙찰자 마이페이지 반영

[실시간 화면]
- 웹 소켓 사용
- 웹 소켓 오류 대비 폴링도 같이 사용
- 현재가 자동 갱신
- 최근 입찰 이력 자동 갱신
- 남은 시간 표시
- 종료 시 입찰 버튼 비활성화

[마이페이지]
- 경매 등록 내역
- 나의 입찰 내역
- 내가 해야하는 결제 및 결제한 구매 내역
- 회원 정보 수정
- 비밀번호 변경

[관리자]
- 관리자 세션 생성(세션 없이 관리자 URL 접근 차단)
- 통계 확인(총 낙찰액, 총 수수료, 미결제 수수료)
- 통계 그래프(일일 경매 등록 현황, 경매 상태 현황)
- 회원 관리
- 경매 관리
- 경매 강제 취소 및 사유 입력
